
# 🏦 Bank Management System

A GUI-based Bank Management System built using **Java Swing**, **JDBC**, and **MySQL**. This application simulates core banking operations like login, deposit, withdrawal, fast cash, mini statement, balance enquiry, and PIN change — all via an ATM-style graphical interface.

## 🚀 Features

- **User Authentication:** Secure login system using account number and PIN.
- **User Registration:** Multi-step form to register new users and store account details in the database.
- **Deposit Module:** Allows users to deposit money and updates account balance accordingly.
- **Withdrawal Module:** Enables cash withdrawal with real-time balance check and validation.
- **Fast Cash:** Predefined withdrawal options (e.g., ₹500, ₹1000, ₹2000) for quick access.
- **PIN Change:** Lets users change their PIN securely with input validation.
- **Balance Enquiry:** Displays real-time account balance fetched from the database.
- **Mini Statement:** Shows recent transactions from the user’s account.
- **Modern GUI:** Java Swing-based graphical interface resembling an ATM machine.
- **JDBC + MySQL Integration:** Reliable data storage and retrieval with SQL operations.

## 🧰 Technologies Used

- Java (JDK 8 or higher)
- Java Swing & AWT (GUI)
- JDBC (Java Database Connectivity)
- MySQL (Database)
- IntelliJ IDEA / Eclipse (IDE)
- MySQL Workbench (Optional GUI for DB)
